# v1.07.5 stabilization release-candidate audit

Baseline: Plugin Hub update under review pinned to v1.06 (18de62d7c0d871101656fc9a33a9db6adec777e3); preceding validated branch v1.07.4 (661b88b361da5c8a9e0d96bdff85530ab440adf7).

## Scope and release gates

- v1.06.1 input compliance: remove global focus APIs and explicit requests; retain native Swing interactions; scan production and tests.
- v1.07.0 rendering: one physical patch footprint, not per-crop clickboxes; existing isolated interaction targets remain.
- v1.07.1 state: dead hops/other crops, clear-only policy, live observation precedence, protected living contracts, optional watering.
- v1.07.2 storage: known versus remembered observations, native placeholders, seed-box reconciliation, widget restoration.
- v1.07.3 runtime: lifecycle/session guards, client thread cleanup, route ownership checks, cached classifications and bank layout.
- v1.07.4 GUI/consolidation: retain controls, shared crop selection/observations, allocation, preparation and decoder logic.
- v1.07.5: the previous bank optimization could drop a stage-change invalidation while the player browsed an unrelated tag; keep the pending stage change until reconciliation. Regression test verifies the personal tab is left alone and the update runs once when returning.

## Compliance review

Current public rules: https://github.com/runelite/runelite/wiki/Rejected-or-Rolled-Back-Features and https://github.com/runelite/plugin-hub. Reviewer objection: https://github.com/runelite/plugin-hub/pull/21369#issuecomment-7186151671.

The original input API guard remains in test and the new release gate screens production for additional forbidden API patterns. It also reports sensitive native widget/script and configuration calls for manual review; it is lexical, not an exhaustive security proof. The production plugin must not inject input, modify other plugins' settings, initiate server actions, load code at runtime, or automate combat. The normal Java 11 target and existing dependencies remain. The native Seed Vault layout uses the generic scrollbar script, local UI state and local widget operations; these are review-sensitive, and must remain transparent to the reviewer. Bank Tags integration reuses its native service, with a temporary registered predicate; confirm native remembered-tab behavior manually. Shortest Path message ownership remains best-effort: its API lacks an atomic ownership token, and unconfirmed routes are left alone.

## Acceptance

Run the clean release gate and test/build on JDK 21. Check generated JAR, test reports and UI previews. Use the comparable maintained/inherited counts emitted by the gate rather than assuming a Git diff equals physical lines. No new dependency, features, configuration identifiers or upstream license removals are intended. Review the player-side matrix in PLUGIN_HUB_REVIEW.md before publication. No actual in-game FPS, real seed-box event timing, native UI behavior, Windows installation or Hub approval is established by CI. Do not merge master or update Plugin Hub until separately authorized.
