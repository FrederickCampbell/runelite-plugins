# Farming Helper v1.11.6 release audit

**Decision — ready for live-client acceptance on the development branch. Publication remains on hold.** The comparison revision is v1.11.5 (`4f9a3ee63b5df95dd0692e59a6f308b7333d3e07`). The main fixes concern bank-aware routing, budgeting for mixed routes and Bank Tags integration.

## Gameplay and integration findings

| Area | Evidence and change |
| --- | --- |
| Bank Tags | Replaced the foreign plugin injector lookup with RuneLite's exported BankTagsService and TagManager bindings and the native BankSearch singleton. The stock Bank Tags plugin supplies those bindings through a declared plugin dependency. Its enabled state gates the shelf. The temporary-layout overload exists on the public concrete BankTagsPlugin and is the one place that still requires that type. Manual tag browsing, placeholders, stage changes and disabled/re-enabled handling have regression coverage. A custom client distribution that omits the built-in plugin entirely is outside this verification. |
| Shortest Path | Bank-item modes in the published implementation already include bank stock. Requiring its separate bank-path setting as well suppressed valid estimates. Both item modes now work with that setting off. Hiding the farming shelf no longer suppresses bank planning. Bank estimates and the displayed destination use distinct public PluginMessage requests. Disabling or enabling Shortest Path resets estimates. Each visit allows one outstanding estimate, a 30-tick reply timeout and a 100-tick total budget. Late replies are ignored. These limits bound the helper's requests. The public protocol offers no per-query worker cancellation. |
| Transport and inventory | Spend pouch contents, loose runes, combination runes, items and staff requirements against each destination. A failed destination releases its tentative reservations. A fallback cannot reuse an already spent tablet. Equipment that conflicts with the required fairy-ring staff is handled conservatively. An unchanged fallback selection can be reused. Independent bank-to-site estimates, spell label recognition and greedy item choices still limit how closely a suggested loadout can match the eventual multi-leg route. |
| Harvest and crop care | Looking up six native item IDs replaces a bank-wide item-name search for herb sacks and reagent pouches. Preserve the carried/open variants and capacity preference. Seed-box confirmed contents, physical inventory capacity, harvesting and crop-preservation rules remain covered by the suite. Replaced deprecated container and diary references with gameval IDs. |
| Time Tracking and Quest Helper | Read per-profile tracker observations and timestamps through native configuration. The embedded attributed registry/decoder supplies plot-level data that the public tracker API does not expose. Live evidence takes precedence where available. Quest Helper installation is unnecessary. Saved observations can be stale away from the patch. |
| Tick, overlay and sidebar | Reviewed state updates at container, profile, widget and plugin transitions. Closed-bank ticks skip empty shelf-release work. Existing scene-target caching keys on tick, world view and plane. Render-time projection and native clickbox geometry still follow the camera. Existing Swing rows refresh in place when the view structure matches. The three static comparisons below cover appearance. Client frame time, Swing flicker and live click accuracy require the checks below. |
| Seed Vault | Coalesce scheduled refreshes and discard them if the view closes or is disabled. Existing native item and scroll behavior remains sensitive to live widget geometry. Automated coverage includes stock changes, view ownership and layout handling. |

The review inventoried all 75 production Java files, screened source and inspected every shipped class. Manual tracing concentrated on the v1.11.1–v1.11.5 changes, event and render entry points, storage manipulation and external integration boundaries. Maintained Java grew from 10,571 to 10,623 lines across the same 68 maintained files. The seven inherited files remain at 3,730 lines. The added destination-level budgeting and rollback account for part of the net increase.

Local tests used a virtual display and an explicitly attached Mockito test agent. The measured evidence supports the two targeted allocation gains. It does not establish a general improvement in game FPS.

## Live-client acceptance before publication

1. Open the bank with a mixed manual run and Shortest Path in a bank-item mode. Leave its separate bank-path toggle off. Check the chosen house or Watchtower spell against actual pouch and loose runes. Where the returned route uses a fairy ring and the diary exemption is absent, verify the staff. Hide the farming shelf and repeat.
2. Try a maximum-size run and a tighter 28-slot setup. Make one destination unaffordable. Check that funded stops retain their supplies, the checklist matches the bank and the guide re-plans after withdrawals. Exercise filled and empty seed boxes, both sack states and the reagent pouch.
3. Use a personal bank tag, switch back to the farming shelf and scroll the Seed Vault before withdrawing and depositing. Verify native click targets, headers, scroll position and the selected items. Check a dense or adjacent plot while rotating the camera and advancing crop-care steps.
4. Replace a helper destination with a personal route. Switch profiles, hop worlds and disable/re-enable the helper and optional integrations. Check stale directions, stock and highlights. When the public protocol cannot distinguish an identical personal destination, ownership remains ambiguous.

A successful live run and separate authorization are required before changing master or the Plugin Hub submission.
