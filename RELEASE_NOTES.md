# Farming Helper v0.7 beta

Basically, Quest Helper, for farm runs.

Choose a farming run, collect your supplies, then follow the highlighted interaction and optional Shortest Path navigation. Includes bank- and Seed Vault-aware crop selection, customizable priorities, merged runs, inventory loadouts, patch exclusions, and exact Quest Helper-derived patch and gardener guidance.

## Install
Download **Source code (zip)** below and extract the complete Gradle project. In RuneLite Dev Manager, use Refresh → Build → Launch. The attached standard plugin JAR is a build artifact, not a standalone RuneLite client.

This is a developer beta. Automated Gradle tests and compilation must pass before publication; live RuneLite behavior has not yet been verified. Not a RuneLite Plugin Hub listing. Shortest Path is optional and separately installed.
